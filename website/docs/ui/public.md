ARGO Monitoring Service provides a set of **publicly accessible views** that can be accessed without logging in. These views allow users to monitor the operational status and performance of services without requiring an ARGO Monitoring account.

The publicly accessible views can be accessed through the navigation menu on the left and include:

* **Dashboard** — provides an overview of the monitored services and their current status.  
* **Availability & Reliability** — provides information about service availability and reliability over time.  
* **Status** — provides the current status and monitoring information for the services.  
* **Capability** — provides information about the metric capability supported by the monitored services.  
* **Performance** — provides performance-related information and historical performance data for services that report performance metrics.

Public users have **view-only access** to these pages. They can browse and inspect the available monitoring information, but they cannot modify configuration, create or update monitoring resources, or perform administrative actions.

Authentication is required to access functionality that allows users to **create, modify, or manage** ARGO Monitoring resources.
