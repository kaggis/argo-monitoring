## **Overview**

The Argo Monitoring Service allows Administrators or Tenant’s Administrators to add registered users directly to their tenant without sending an invitation. This functionality provides a quick and straightforward way to grant access to users who already have an account in the Argo Monitoring Service.

By assigning a role during the process, it can be ensured that users receive the appropriate permissions to perform their responsibilities within the tenant. This functionality is available under the Members section, in the Add Member tab.

| This action can be performed by both Super and Tenant Administrators and any user with access to a Tenant in Argo Monitoring Service, assigned with a role that is allowed to perform this action. .  |
| :---- |

## **Why Use Add Member?**

The Add Member functionality simplifies tenant access management by allowing administrators to:

* Add existing registered users directly to the tenant.  
* Assign a role and the corresponding permissions to each user.  
* Grant access without requiring the user to accept an invitation.  
* Manage tenant membership efficiently from a single interface.

This approach is particularly useful when the user is already registered in the Monitoring Service and can be identified by their email address or name.

## **Adding a Member**

Administrators or Tenant Administrators can add an existing registered user directly from the Add Member section.

To add a member:

1. Visit the Monitoring Service and **log in.**  
2. Navigate to the **Members section**.  
3. Open the **Add Member** tab.  
4. In the **Search User** field, search for a registered user by entering their email address or name.  
5. Select the **desired** **user** from the search results.  
6. Select the **appropriate** **role** for the user.  
7. Click **Add Member** to confirm the action.

Once the action is completed, the selected user is added directly to the tenant with the assigned role and associated permissions.

| Note: The Add Member functionality is intended to add users who are already registered in the Monitoring Service. For users who do not yet have an account, Tenant Administrators can use the Invitations functionality to invite them to join..  |
