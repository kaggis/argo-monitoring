The Monitoring Service supports multi-tenant user management, allowing **Tenant Administrators** to securely invite and manage additional users to collaborate within their specific tenant workspace.

## Members

To manage access, Tenant administrators navigate to the members management page. The first page is the list of members which displays the full list of all active users currently belonging to the tenant. At the same time it allows (super\_admin, tenant\_admin) administrators to audit who has access and review their assigned operational roles.

![](/img/ui/image22.png)

![](/img/ui/image4.png)

One of the main actions an (super\_admin, tenant\_admin) administrator can do is revoke the access from the selected user.
